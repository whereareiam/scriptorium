# Getting Started

1. Add your docs under `docs/content`.
2. Add branding assets under `docs/assets`.
3. Fill in `scriptorium.project.json`.
4. Run the ref staging step before building.

## Notes

Use absolute `/assets/...` paths when you want stable branding or image URLs across all published refs.

## Ref Metadata

Use the `refs` object in `scriptorium.project.json` to give branches or tags friendly names and short descriptions in the selector UI.

The starter example is configured with `release` as the default ref, `dev` as a secondary branch, and numeric tags like `1.0.1` so you can see the selector behavior immediately.
