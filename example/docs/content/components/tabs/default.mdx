# Tabs

`Tabs` and `Tab` are the built-in Fumadocs tab components exposed by the Scriptorium MDX setup.

## Example

<Tabs items={['Java', 'Kotlin']}>
  <Tab value="Java">Java is explicit and familiar.</Tab>
  <Tab value="Kotlin">Kotlin keeps the same ecosystem with a more concise syntax.</Tab>
</Tabs>

## Usage

```mdx
<Tabs items={['Java', 'Kotlin']}>
  <Tab value="Java">Content for the first tab.</Tab>
  <Tab value="Kotlin">Content for the second tab.</Tab>
</Tabs>
```
