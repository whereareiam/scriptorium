# Getting Started

1. Add your docs under `docs/content`.
2. Add branding assets under `docs/assets`.
3. Fill in `scriptorium.project.json`.
4. Run `bun run dev` or `bun run build`. Scriptorium stages docs automatically.

## Notes

Use absolute `/assets/...` paths when you want stable branding or image URLs across all published refs.

## Versions

Use the `versions` block in `scriptorium.project.json` to:

- choose the home version for `/docs`
- include exact branches or tags
- include wildcard patterns such as `release/*`
- add optional labels and theme overrides for exact published versions

The example fixture uses `dev` as the home version and includes matching `release/*` branches plus all tags when they exist.
