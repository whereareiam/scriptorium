# Overview

This starter is built for projects that want:

- one docs site per project
- a shared shell across projects
- version selection for `dev`, `release/*`, and tags

This example exposes:

- `dev` as the home version
- matching `release/*` branches when they exist
- all tags when they exist

## Contract

Your project repo provides:

- `docs/content/**`
- `docs/assets/**`
- `scriptorium.project.json`
