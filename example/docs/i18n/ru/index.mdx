# Обзор

Этот шаблон подходит проектам, которым нужны:

- отдельный сайт документации для каждого проекта
- общая оболочка для всех проектов
- выбор версии: `dev` и теги

В этом примере:

- `dev` открывается по умолчанию
- публикуются все теги, если они есть

## Контракт

Репозиторий проекта предоставляет:

- `docs/content/**`
- `docs/assets/**`
- `docs/i18n/<язык>/**` — переводы, по желанию
- `scriptorium.project.json`
