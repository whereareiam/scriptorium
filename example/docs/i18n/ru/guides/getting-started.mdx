# Начало работы

1. Положите документацию в `docs/content`.
2. Положите логотип и другие файлы оформления в `docs/assets`.
3. Заполните `scriptorium.project.json`.
4. Запустите `bun run dev` или `bun run build`. Scriptorium подготовит документацию сам.

## Заметки

Используйте абсолютные пути `/assets/...`, если адреса логотипа и изображений должны быть одинаковыми во всех опубликованных версиях.

## Версии

Блок `versions` в `scriptorium.project.json` позволяет:

- выбрать версию, которая открывается по адресу `/docs`
- включить конкретные ветки или теги
- задать подписи и цвета для отдельных опубликованных версий

В этом примере по умолчанию открывается `dev`, а также публикуются все теги, если они есть.
